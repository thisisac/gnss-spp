# Deployment / 发布说明

## 中文

本项目是 Windows 研究/课程程序，不提供安装包或服务部署脚本。公开发布时建议只提交源码、文档和经过许可的示例结果，不提交原始 GNSS 数据、私有网络地址或个人信息。

## English

This is a Windows research/course program and does not provide an installer or service deployment script. For public release, include only source, documentation, and redistributable example results; do not publish raw GNSS data, private endpoints, or personal information.
